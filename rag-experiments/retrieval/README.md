# Retrieval 实验 - 检索策略优化

## 实验状态

✅ **已完成** (2026-05-03)

## 实验目的

测试和优化RAG系统的检索策略，包括混合检索、重排序、查询扩展等技术在金融场景的效果。

## 测试策略

| 策略 | 说明 |
|------|------|
| 纯向量检索 | 仅使用向量相似度 |
| 纯BM25检索 | 仅使用关键词匹配 |
| 混合检索(RRF) | RRF融合向量+BM25 |
| 混合检索(线性α=0.5) | 线性融合，等权重 |
| 混合检索(线性α=0.7) | 线性融合，偏向向量 |

## 实验结果

### 策略对比

| 策略 | R@1 | R@5 | P@5 | MRR |
|------|:---:|:---:|:---:|:---:|
| 纯向量检索 | 0.000 | 0.250 | 0.050 | 0.094 |
| 纯BM25检索 | 0.250 | 0.500 | 0.100 | 0.354 |
| 混合检索(RRF) | 0.125 | 0.125 | 0.025 | 0.125 |
| 混合检索(线性α=0.5) | 0.125 | 0.250 | 0.050 | 0.167 |
| 混合检索(线性α=0.7) | 0.000 | 0.125 | 0.025 | 0.031 |

### 关键发现

1. **BM25在金融关键词检索上优势明显**
   - Recall@5达到50%，是纯向量的2倍
   - MRR达到0.354，远超其他策略

2. **混合检索在本场景未体现优势**
   - RRF融合后效果反而下降
   - 可能是向量检索噪声影响了结果

3. **金融文档适合关键词优先策略**
   - 股票代码、财务指标等结构化关键词
   - BM25的精确匹配更可靠

## 优化建议

1. **金融场景推荐**: 纯BM25或BM25为主的混合策略
2. **语义模糊查询**: 补充向量检索作为fallback
3. **元数据过滤**: 股票代码精确匹配优先
