## 一、新增模块

### 1. 数据爬虫 (data_crawler.py)

**功能：**
- 批量获取A股历史K线数据（新浪接口，绕过代理）
- 获取上证指数日K线（腾讯接口）
- 获取每日涨停池数据
- SQLite本地缓存，避免重复下载
- 支持增量更新

**使用方法：**
```bash
cd ~/Desktop/four-shrimp
./venv/bin/python3 scripts/utils/data_crawler.py
```

**数据缓存位置：** `~/Desktop/four-shrimp/data/market.db`

### 2. 历史回测引擎 (historical_backtest.py)

**功能：**
- 每日扫描市场环境（每日大盘虾）
- 自选股交易面/基本面/政策面扫描
- 自动生成交易信号
- 支持止盈/止损/移动止盈/持仓到期自动卖出
- 各虾独立回测 + 融合信号回测

**回测参数：**
- 止损：-7%
- 止盈：20%
- 移动止盈：回撤10%
- 最大持仓：20天
- 单票仓位：最大10%

**使用方法：**
```bash
./venv/bin/python3 scripts/backtest/historical_backtest.py
```
